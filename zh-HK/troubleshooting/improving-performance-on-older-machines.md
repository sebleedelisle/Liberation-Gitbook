# ✅ 改善舊款電腦的效能

如果你使用較舊或規格較低的電腦，Liberation 在處理較大型 project 或複雜 layout 時，可能會較難保持流暢。

### 檢查 frame rate

查看頂部列的 frame rate 指示器。它會顯示兩個數值：目前 frame rate 和目標 frame rate。

如果目前 frame rate 明顯低於目標 frame rate，或低於每秒 20 或 30 幀，減少 Liberation 需要處理的工作量可能會有幫助。

### 可嘗試的方法

* 從系統中移除所有未使用的雷射。
* 從 3D Visualiser 移除所有未使用的雷射。
* 在 Settings 中把 3D Visualiser 調到盡量細小。
* 如果你沒有使用 Timeline，請從 **View > Timeline** 關閉它。
* 如果你正在使用 Timeline，請將 Clip Deck 捲動到空白區域。
* 降低顯示器解像度，或縮小 Liberation 視窗。你可以在 Settings 調整 Liberation UI 大小作補償。
* 關閉 Liberation 中任何未使用的 panel。
* 關閉電腦上的其他應用程式。

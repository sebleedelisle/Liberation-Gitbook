# ✅ Improving performance on older machines

If you are using an older or lower-spec computer, Liberation may struggle to keep up with larger projects or complex layouts.

### Check the frame rate

Look at the frame rate indicator in the top bar. It shows two numbers: the current frame rate and the target frame rate.

If the current frame rate is dropping well below the target frame rate, or below about 30 frames per second, reducing the amount of work Liberation has to do may help.

### Things to try

* Remove any lasers you are not using from the system. For example, if you only have one laser connected, delete the others.
* Remove any unused lasers from the 3D Visualiser.
* Make the 3D Visualiser as small as possible in Settings.
* If you do not need the 3D Visualiser, switch to the Output or Canvas view.
* If you are not using the Timeline, turn it off from **View > Timeline**.
* If you are using the Timeline, scroll the Clip Deck to an empty area.
* Reduce the resolution of your display, or make the Liberation window smaller. You can compensate by adjusting the Liberation UI size in Settings.
* Close any unused panels in Liberation.
* Close other apps on your computer.
* Pause or close background utilities such as antivirus scans, Dropbox or other cloud sync apps, and any unnecessary network or firewall tools while testing.

If none of this helps, you may need to use a faster computer.
